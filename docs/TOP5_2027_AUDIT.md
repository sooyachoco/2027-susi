# 2027 수시 TOP5 데이터 감사

검증 대상: 서울대, 연세대, 서강대, 고려대, 중앙대
기준일: 2026-09-04

## 1. 데이터 구조 감사

TOP5는 aggregate 전형 데이터와 학과별 상세 전형 데이터가 동시에 repository에 연결되어 있다.

- aggregate: `*-2027-aggregate` departmentId
- 상세: 대학별 실제 모집단위 departmentId
- 현재 `dedupeByKey()`는 admission `id`만 기준으로 중복 제거한다.
- 따라서 aggregate와 상세 admission은 서로 다른 id를 가지며 동시에 반환될 수 있다.

## 2. 추천 엔진 관점의 핵심 발견

`getAdmissions()`가 aggregate를 그대로 반환하면 대학별 모집인원을 합산하는 소비 코드에서 aggregate + 상세 모집인원이 함께 계산될 위험이 있다.

따라서 TOP5처럼 학과별 상세 데이터가 완성된 대학은 추천/분석용 admission 목록에서 aggregate admission을 제외하고, aggregate는 대학/전형 총량 표시용으로만 사용하는 구조가 안전하다.

## 3. 고려대 공식 데이터 대조

고려대 2027 서울캠퍼스 최종 수시요강 기준 주요 총량:

- 학교추천 650
- 학업우수 903
- 계열적합 523
- 고른기회 201
- 다문화 20
- 재직자 18
- 사이버국방 10
- 논술 351
- 특기자 55

특기자 55는 체육교육과 40 + 디자인조형학부 15로 별도 상세 연결되어 있다.

## 4. 다음 수정 원칙

1. TOP5 상세 데이터가 존재하는 대학은 aggregate admission을 추천 계산 대상에서 제외한다.
2. aggregate department는 UI/대학별 총량 표시를 위해 유지한다.
3. 대학별 상세 전형 모집인원 합계와 공식 aggregate를 전형별로 비교한다.
4. 합계 불일치가 발견되는 경우 상세 데이터를 공식 모집요강 기준으로 먼저 수정한다.
5. aggregate는 상세 데이터를 다시 합산해 생성할 수 있는 파생 데이터로 취급한다.
