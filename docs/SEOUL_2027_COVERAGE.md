## 작업 원칙

- 서울 캠퍼스 기준으로만 집계한다.
- 경기·인천 대학은 이번 단계에서 추가하지 않는다.
- 1차 우선순위로 미루기로 한 8개교는 별도 보류한다: 서울대, 연세대, 고려대, 서강대, 중앙대, 경희대, 한국외대, 이화여대.
- 나머지 서울권 대학부터 실제 2027학년도 전형/모집단위 데이터를 보강한다.
- `expanded2027.ts`의 `isMock: true` 데이터는 실제 추천 데이터로 사용하지 않는다.
- 대학별 최종 모집요강과 대입정보포털/대학 공식 시행계획을 교차검증한 데이터만 검증 데이터로 편입한다.
